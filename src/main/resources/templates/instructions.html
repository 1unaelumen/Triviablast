Singleplayer Mode

How it works

In singleplayer mode, you answer questions one by one and try to get the highest score possible.

  1. Choose the number of questions.
  2. Select a category and difficulty.
  3. Press Start Game.
  4. Select one answer for each question.
  5. Press Next Question to continue.
  6. When all questions are finished, the Game Over screen appears.

Scoring

  • Correct answer: +10 points.
  • Wrong answer: 0 points.
  • You can only select one answer per question.
  • The game ends when all questions are completed.
